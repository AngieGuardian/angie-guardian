# Vendored Argon2 reference source

This directory contains the minimal source subset used to build Guardian's
browser Argon2id WebAssembly module from the official PHC reference repository:

- upstream: `https://github.com/P-H-C/phc-winner-argon2`
- commit: `f57e61e19229e23c4445b85494dbf7c07de721cb`
- license: CC0-1.0 or Apache-2.0 (see `LICENSE`)

Run `scripts/build-argon2-wasm.sh` to reproduce the embedded artifacts.
